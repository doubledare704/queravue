# Oracle

Package `core/internal/engine/oracle`, built on `github.com/sijms/go-ora/v2` (pure Go, MIT, no Instant Client). Password authentication only; Oracle 12c or later (`FETCH FIRST`, identity columns). Developed against Oracle Database Free 23.

Connection form: host, port (1521), service name, SID (used when there is no service name), TNS descriptor (used instead of host, port and service when set), user, password (keychain), role (`normal` or `sysdba`), TCPS, "Verify server certificate", wallet directory, "Show Oracle-maintained schemas".

URI forms accepted by "paste a connection string":
- `oracle://user:password@host:1521/SERVICE?sid=X&role=sysdba&ssl=true&wallet=/path`
- Easy Connect: `host:1521/SERVICE` or `//host/SERVICE`, with an optional `user/password@` prefix
- a TNS descriptor, with the same optional prefix. A plain single-address descriptor fills the host, port and service (or SID) fields, and `PROTOCOL=TCPS` turns TCPS on. Anything else (several addresses, `ADDRESS_LIST`, failover) is kept whole in the descriptor field.

## Behaviour
- **Dialect:** `"ident"` quoting, `:1` placeholders, `FETCH FIRST n ROWS ONLY`, `NULLS FIRST/LAST`, `TIMESTAMP '…'` and `HEXTORAW('…')` previews. Names are quoted exactly as the schema tree reports them, so `EMPLOYEES` and `"employees"` stay distinct tables. Completion inserts a name unquoted only when it is upper case, simple and not reserved.
- **Splitting:** `sqlsplit` has an Oracle lexer. `q'[…]'`, `nq'{…}'` and the other delimiters are skipped. A `/` alone on a line ends a statement. `BEGIN`, `DECLARE` and `CREATE [OR REPLACE] PROCEDURE | FUNCTION | PACKAGE [BODY] | TRIGGER | TYPE BODY` run to the next `/` line, so the semicolons in their bodies do not split them. Plain statements end at `;`. Execution strips the `;` or `/` the server would reject and keeps the `;` a PL/SQL block needs.
- **Transactions:** the driver commits after every statement unless a transaction is open. `SET TRANSACTION …`, `COMMIT` and `ROLLBACK` are turned into a driver transaction held on the connection, which is what the table editor and the designer use. DDL commits implicitly in Oracle, so a designer script is not transactional and says so in its warnings.
- **Schema:** the connection reaches one container, so the only "database" is its name (`CON_NAME`). Schemas are users from `ALL_USERS`; Oracle-maintained ones (`ORACLE_MAINTAINED = 'Y'`) are hidden unless the connection shows them. Tables, views and materialized views come from `ALL_OBJECTS` (recycle-bin and materialized-view container tables left out). Columns, constraints and indexes come from `ALL_TAB_COLUMNS`, `ALL_CONSTRAINTS`, `ALL_CONS_COLUMNS`, `ALL_INDEXES`, `ALL_IND_COLUMNS` and `ALL_IND_EXPRESSIONS`, always filtered by owner. Row estimates are `NUM_ROWS`, so they are `-1` until statistics are gathered.
- **Editing:** by primary key, or by a unique index over `NOT NULL` columns; otherwise read-only with a reason. Views are read-only.
- **Designer and schema plan:** `CREATE TABLE` with identity columns (`GENERATED BY DEFAULT AS IDENTITY`), `ADD`, `MODIFY`, `RENAME`, `DROP COLUMN`, constraints and indexes. Foreign keys accept only `ON DELETE CASCADE` and `ON DELETE SET NULL` (other rules are refused with the reason); there is no `ON UPDATE`. A default on an identity column and switching a column to or from identity are refused.
- **Indexes:** b-tree and bitmap, descending keys, function-based keys, `ONLINE` builds (needs a server edition that has the feature). Sizes come from `ALL_SEGMENTS`. Usage is not reported.
- **Cancel:** the driver sends a break when the context ends. Verified against Free 23 (`TestIntegrationCancelRunningStatement`, `CancelMidStream`): a streaming query, a query that computes before its first row, a long `DELETE` and a PL/SQL busy loop stop in about 0.6 s with ORA-01013, and the session stays usable.
- **Positions:** a syntax error carries the 1-based character offset the server reports.

## Types
| Oracle type | Value |
|---|---|
| `NUMBER(p)` with p ≤ 18, `NUMBER(p,0)` | int |
| `NUMBER` without precision, `NUMBER(p,s)`, `FLOAT`, p > 18 | decimal (exact text, so `COUNT(*)` is a decimal too) |
| `BINARY_FLOAT`, `BINARY_DOUBLE` | float |
| `DATE` | timestamp, with the time of day (no zone, shown as UTC) |
| `TIMESTAMP` | timestamp (no zone, shown as UTC) |
| `TIMESTAMP WITH TIME ZONE` | timestamp with its offset |
| `TIMESTAMP WITH LOCAL TIME ZONE` | timestamp, as the driver converts it for the session |
| `INTERVAL DAY TO SECOND`, `INTERVAL YEAR TO MONTH` | text (`+04 05:06:07.089000`, `+02-03`) |
| `CLOB`, `NCLOB`, `LONG` | text, capped (below) |
| `BLOB`, `RAW`, `LONG RAW` | bytes, capped for LOBs |
| `ROWID`, `UROWID` | text (read-only in practice: the editor does not write columns it did not change) |
| everything else (`VARCHAR2`, `CHAR`, `XMLTYPE`, …) | text |

## Known limitations
- **LOB size cap.** go-ora reads a LOB whole, so a cell is cut to 1 MiB after the driver has read it (text ends with `… [truncated]`). Streaming LOBs from the server (`LOB FETCH=POST`) was measured and does not help: the live heap is the same and small LOBs are about 80 times slower (`docs/perf/iteration-10.md`). The cut value is never written back by the editor, which sends only the cells a user changed.
- **Cancel does not interrupt a wait inside `DBMS_SESSION.SLEEP` or `DBMS_LOCK.SLEEP`.** The break is sent, but the call ran to its end in the test (20 s). Other waits were not measured.
- **TCPS and wallets are passed through, not tested.** The dev container has no TCPS listener. The wallet option points at a directory with an auto-login wallet (`cwallet.sso`); a wallet that needs a password is not supported, because a connection has one secret. Kerberos, OS authentication and external authentication are not supported.
- **One result per statement.** Implicit result sets, ref cursors and `RETURNING … INTO` bind variables are not supported; `DBMS_OUTPUT` is not collected as notices.
- **`ORA-` messages** keep the driver's text. The password is removed from them.
- **Types not in the table** (`JSON`, `VECTOR`, `BOOLEAN` of 23ai, object types) arrive as whatever the driver returns, converted to text. They have not been checked.
- **Edge case:** `SELECT` statements that start with a hint comment are recognised, but `EXPLAIN PLAN FOR …` runs as a statement without rows.
- **SSH tunnel:** go-ora has a dial hook, so the tunnel needs no local forward. See ADR 0018.

## Dev database
`gvenzl/oracle-free:23.26.3-slim-faststart` (native arm64), service `FREEPDB1`, user `queravue` (password `queravue`), `SYS`/`SYSTEM` password `Queravue_dev1`. The seed in `dev/seed/oracle/` runs on the first start of a fresh volume and quotes every name in lower case, because the shared `enginetest` suite uses lower-case names and `Target.Ident` quotes the raw SQL it writes. Real Oracle schemas are usually upper case and work the same way.

## Testing
```bash
docker compose -f dev/docker-compose.yml up -d --wait oracle
cd core && go test -tags=integration ./internal/engine/oracle/
ORACLE_PERF=1 go test -tags=integration -run Perf -v ./internal/engine/oracle/
```
Override with `ORACLE_HOST`, `ORACLE_PORT`, `ORACLE_SERVICE`, `ORACLE_USER`, `ORACLE_APP_PASSWORD` and `ORACLE_PASSWORD` (the `SYS` password, used by the SYSDBA and cross-schema tests). The shared suite skips the cross-schema relation test, because a foreign key into another schema needs a `REFERENCES` grant from that schema's owner; `TestIntegrationCrossSchemaForeignKey` covers it with a SYSDBA connection.
